# Decision records are written by every agent, and the index is generated

- **Date:** 2026-10-31
- **Status:** Accepted
- **Deciders:** Stefan
- **Area:** agent tooling, docs

## Context

The *why* behind benchmark and engine choices was scattered across package
README changelogs, commit messages, and conversations. Two people work on the
repository with different agents (Claude Code and Codex), so a convention that
only one agent sees, or that depends on someone remembering to run a command,
would be followed unevenly.

## Decision

Trade-off decisions live as one dated, append-only file each in
`docs/decisions/`, modeled on the Helix repository. The instruction to write them
lives in `AGENTS.md`, which both agents load (`CLAUDE.md` imports it). The index
is generated by `scripts/decision-index.py`: the shared Stop hook
`scripts/agent-hooks/stop-checks.sh`, used by both `.claude/settings.json` and
`.codex/hooks.json`, rebuilds it, and `scripts/verify.sh` rejects a stale one.

## Consequences

- Neither agent needs to remember the index; a session that adds a record ends
  with a rebuilt index.
- A record without a `# Title` or `- **Date:**` line fails verification.
- Filenames carry no number, so parallel branches cannot collide on one, and
  `INDEX.md` merges with `merge=union`.
- Package README changelogs remain for small package facts;
  `capture-tacit-knowledge` routes trade-off decisions here instead.

## Alternatives considered

- **Numbered ADRs (`0001-…`).** Helix dropped numbers after repeated collisions
  between branches.
- **Hand-maintained index.** Every branch inserts at the same line and conflicts.
- **Agent-specific hooks or skills only.** Would leave one of the two agents
  without the convention.
